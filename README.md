# ことのは相談室

3人の相談相手から1人を選んで、チャットで相談できる Web アプリです。

| 相談相手 | 人柄 | 話し方 | 回答の切り口 |
| --- | --- | --- | --- |
| 源じい | 心穏やかで気さく、知恵が豊富なおじいちゃん | 「わし」「〜じゃのう」「〜してみんさい」 | 長い目で見る。ことわざや暮らしのたとえ話で見方を変える |
| ひなた | おもてなしの心にあふれた、笑顔のお姉さん | 「わたし」、やわらかい「です・ます」 | まず気持ちを受け止め、ねぎらう。心と体をいたわる小さな一歩 |
| レン | 頭の回転が速く、実践的なお兄さん | 「俺」「〜だね」「〜しよう」 | 状況を整理し、選択肢を3つ以内で示す。最後に「今日やること」 |

- 入力はキーボードと音声（マイクのボタン）の両方に対応しています
- モードは2つあります。「自分から相談する」は相談者が話し始め、「話しかけてもらう」は相談相手のほうから話しかけ、問いかけながら会話を進めます。最初の一言は「時間帯のあいさつ」＋「その日の話題」で、話題は毎日変わります（相談相手ごとに14種類を日替わりで一巡）
- 会話は吹き出しで続き、モードと相談相手ごとに別々に保たれます
- 会話はブラウザを開いている間だけ残り、再読み込みすると消えます（端末にも保存しません）

## 相談相手が守る約束

返事は AI（Claude）が作ります。どの相談相手にも、次の約束を守らせています（`lib/prompts.ts`）。

- 人格攻撃をしない。見下す・からかうなど、相談者が不快になることを言わない
- 法律やモラルに反することを勧めない、やり方を教えない
- 医療・法律・お金の専門的な判断は断定せず、専門家や公的な窓口を勧める
- 命の危険がうかがえるときは、真剣に受け止めて相談窓口を案内する

AI の返事はこの約束に沿うよう指示していますが、常に完全であることは保証できません。公開する場合は、実際に使って確かめながら運用してください。

## 音声入力について

ブラウザの音声認識機能（Web Speech API）を使います。Chrome・Edge・Safari で使えます。対応していないブラウザ（Firefox など）ではマイクのボタンが表示されません。Chrome や Edge では、音声はブラウザの提供元の音声認識サービスで文字に変換されます。

## 環境変数

| 名前 | 必須 | 内容 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 必須 | [Claude Console](https://platform.claude.com/) で発行した API キー |

相談のたびに API の利用料金がかかります。利用者を限定する仕組みはないので、アプリの URL を知っている人は誰でも利用でき、その料金は API キーの持ち主にかかります。公開する場合は、Claude Console で利用額の上限を決めておくと安心です。

## 手元で動かす

[Node.js](https://nodejs.org/ja)（20.9 以上）が必要です。

```
npm install
npm run dev
```

`.env.example` を `.env.local` という名前でコピーし、値を書き込んでから起動します。ブラウザで http://localhost:3000 を開きます。

## Vercel にデプロイする

1. このフォルダを GitHub のリポジトリにプッシュする
2. [Vercel](https://vercel.com/new) で「Add New… → Project」からそのリポジトリを選ぶ
3. 「Environment Variables」に上の環境変数を登録して「Deploy」

## 構成

| パス | 内容 |
| --- | --- |
| `app/page.tsx` | チャット画面（相談相手の切り替え、入力、音声入力） |
| `app/api/chat/route.ts` | 会話を Claude API に送り、返事を少しずつ返す API |
| `lib/personas.ts` | 相談相手の名前・あいさつ・話しかけの最初の一言など、画面に出す情報 |
| `lib/prompts.ts` | 相談相手の性格・口調・守る約束（返事の内容を変えたいときはここ） |
| `components/Avatar.tsx` | 3人のアバター（SVG） |
| `app/globals.css` | 全体のスタイル（色は先頭の CSS 変数で変更可能） |
